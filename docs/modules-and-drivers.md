# 独立模块与完整驱动（1.13.0）

Minecraft 1.21.1 / NeoForge 21.1.233 / Java 21。开发板、GPIO、软件I²C和电子模块可以独立使用；机械动力和Sable都是可选集成。

## MPU6050 惯性传感器

七位地址默认68H，潜行空手右键切换AD0至69H。WHO_AM_I始终为68H。SDA/SCL接开发板配置的同名GPIO，附录默认P1.6/P1.7。

|寄存器|用途|
|---|---|
|19H / 1AH|采样分频 / CONFIG，保存读回|
|1BH / 1CH|陀螺仪 / 加速度量程，选择位4:3|
|38H / 3AH|中断使能保存 / 数据就绪状态，读3AH清除|
|3BH–40H|AX、AY、AZ，16位有符号、大端|
|41H–42H|温度原始值，℃=raw/340+36.53|
|43H–48H|GX、GY、GZ，16位有符号、大端|
|6BH|复位80H、休眠40H、唤醒00H|
|6CH|各轴待机位|
|75H|身份68H|

加速度四档±2/4/8/16g，对应16384/8192/4096/2048 LSB/g；陀螺仪四档±250/500/1000/2000°/s，对应131/65.5/32.8/16.4 LSB/(°/s)。本地轴X=东、Y=北、Z=上。一次读事务锁存整帧。

普通静止方块输出+1g和零角速度；Sable运动结构读取真实加速度、角速度。模块只提供原始数据，姿态解算由玩家固件完成。温度固定25℃。这是常用原始寄存器子集，不实现DMP、FIFO、辅助主I²C、自检、硬件中断引脚和真实噪声。数据每tick更新一次，正常20Hz；CONFIG/分频不产生1kHz物理子采样或硬件DLPF。电源、量程、地址等配置会随存档保存。

## ALT-01 高度计

本模组自定义I²C高度计，地址76H。普通世界读取模块中心的世界Y，Sable上跟随实际物理位置和垂直速度。高度不要求附近存在地面。

|地址|格式与用途|
|---|---|
|00H / 03H|身份41H / 协议1|
|01H|bit0有效、bit1位于运动结构|
|02H|每tick递增的8位序号|
|04H–07H|绝对高度，有符号32位cm，小端|
|08H–09H|垂直速度，有符号16位cm/s，小端|
|0AH–0DH|保存的零点，有符号32位cm|
|0EH–11H|相对零点高度，有符号32位cm|
|12H|写A5H捕获当前零点|

零点保存到存档。注意它采用小端，与MPU6050的大端不同。

## 多通道电机接口

每块接口只操作紧贴其六个面的机械动力创造马达，方向编号固定为下0、上1、北2、南3、西4、东5。六路独立接受−256～+256RPM。无机械动力时仍能正常接入I²C并读写状态，马达检测掩码为0。

默认地址60H，SAFE时潜行空手右键在60H–67H间循环；地址保存。同一总线可用八块不同地址接口，共48路。另一对GPIO可建立另一条软件总线。重复地址会在接线一览报告冲突。

|地址|用途|
|---|---|
|00H / 03H|身份4DH / 协议1|
|01H|读bit0为允许状态；写A5H允许，写其他值停机|
|02H|状态序号|
|04H|六方向相邻马达掩码|
|05H|有线控制器运行状态|
|20H–2BH|六路有符号16位小端RPM暂存区|
|2CH|写A5H原子提交六路并刷新看门狗|

断线、主板停止、重载或超过4tick未收到活动会关闭接口并将相邻马达指令归零。允许操作给予首次提交宽限；已有转子惯性会保留。固件应持续提交完整六路命令。

## 线缆与引脚

使用现有线卷分别点击两个端子连接，接线柱可分支，线名相同可自动配对。软件I²C可以使用任意合适的GPIO，模块采用SDA/SCL名称。所有外设都通过协议访问，不占用STC的IDATA、SFR或XDATA映射窗口。

移动结构的线路显示、距离和选取使用世界位置。建议先完成Sable装配再布线；目前不保证拆装或旋转搬移自动迁移已连线路，创建后也没有线缆拉断物理。

## 手册附录与源码

手册有46个双语条目，分入门、开发、模块、速查、附录五类。附录包含11组通用驱动和40份完整C/H文件（含最小主程序），从 `examples/drivers` 逐字生成。每个代码块的复制按钮复制完整文件，分页显示不截断复制内容。

覆盖MPU6050、ALT-01、电机接口、PCF8591、环境传感器、九键/LED、红石接口、八段数码管、DS1302、DS18B20和SSD1306。公共平台头文件、软件I²C、Timer0延时、字库、依赖表、端序、单位和返回值均提供。

默认驱动时序为12MHz/12T，特别是DS18B20短采样槽。各最小程序是独立项目，组合前需规划引脚；数码管P2与按钮9的P2.0冲突，RTC默认P3.0/P3.1与UART冲突。I²C默认SDA=P1.6、SCL=P1.7。实际编译验证使用SDCC，Keil声明分支未在Keil编译器中验证。完整使用说明见[驱动README](../examples/drivers/README.md)。

```powershell
./tools/build-driver-examples.ps1
./gradlew.bat verifyDriverExamples
```

11组最小程序均以8KiB Flash和256B内部RAM限制编译，并在实际8051解释器执行验证，覆盖I²C、OLED、GPIO、RTC时间/RAM、DS18B20负温度、ROM搜索、CRC和分辨率等。

MPU寄存器参考[InvenSense原厂手册（Olimex镜像）](https://www.olimex.com/Products/Modules/Sensors/MOD-MPU6050/resources/RM-MPU-60xxA_rev_4.pdf)。可选集成源码：[Create](https://github.com/Creators-of-Create/Create)、[Sable](https://github.com/ryanhcode/sable)。
